# The Lab

Welcome to the source code for The Lab. This is a personal project showcase website where I document hardware modifications, console homebrew, and software experiments.

The site features a modern Glassmorphism design with a responsive grid layout that adapts to mobile devices.

## Features

- Glassmorphism UI: Semi-transparent panels with background blurring.
- Signature Theme: Dark mode background with a dynamic gradient animation and Lime Green accents.
- Responsive Grid: A CSS Grid layout that switches from a 3-column view on desktop to a single column on mobile.
- Fade Animations: Elements smoothy fade in as you scroll down the page.
- Pure Code: Built with standard HTML5, CSS3, and Vanilla JavaScript (no frameworks required).


Like most of my projects, this is almost entirely AI genarated.
